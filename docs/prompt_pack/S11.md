## S11 — Parent Confirmation (QR + OTP), optional

Skip entirely if D-11 stays disabled (record "disabled" in `STATE.md`).

**Allowed files:** `src/omr_dispatch/confirmation.py`, `tests/test_stage11_confirmation.py`.

- Scoped strictly per org (`org_id`) and per sender (`sender_id`); applies only to PTM-linked assessments (`is_ptm_linked=True`). Cryptographically random opaque token scoped to org/student/test/PTM event; store only its hash; QR contains only a secure URL with the opaque token.
- Expiry, revocation, single use, replay protection, rate limits (≤ 5 attempts), HTTPS, CSRF where relevant, audit trail.
- Confirmation requires an OTP challenge sent to the verified guardian contact using the calling org sender's registered authentication template when the sender status is `READY` (ADR-0019). Record verification method and time; claim no stronger assurance than the mechanism provides. Paper signature stays optional and unverified.

**Gate 11:** expiry, reuse, revocation, wrong-token, OTP failure/lockout, unauthorised access, token randomness/length, success path, no personal data in the QR payload. `pytest -q tests/test_stage11_confirmation.py`.
