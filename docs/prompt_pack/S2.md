## S2 — Input Contracts and Import (new)

**Goal:** Define how data enters the system. No scoring.

**Allowed files:** `src/omr_dispatch/models.py`, `config.py`, `ingestion.py`, `docs/input_contracts.md`, `tests/test_stage2_ingestion.py`, `fixtures/ingestion/**`.

**Tasks**
1. Strict Pydantic v2 models (`extra="forbid"`): `SubjectName`, `QuestionMeta` (id, subject, question_type per ADR-0004 with SINGLE_CORRECT supported and others raising NotSupportedError, positive_marks, negative_marks, optional bubble coords), `StudentAdmissionRow` (id, org_id if confirmed per ADR-0003, roll, Hindi display name/salutation, raw student/guardian contact, sibling-verification, guardian verification, consent status/scope/time/source/reference, revocation), `StudentOMRSubmission` (id, org_id if confirmed, PRESENT/ABSENT, responses, scan reference, provenance), `CoordinateMap`, `ScanProvenance`. All serialized models carry a `schema_version: int` (ADR-0006). A typed `Settings` object in `config.py` validates environment configuration at startup with `SecretStr` for credentials and safe defaults (ADR-0009).
2. Importers for roster/answer-key/responses (CSV and JSON). Reject unknown columns, duplicate IDs, out-of-range question IDs, invalid options, and missing records. Never treat a missing record as zero. Preserve each decoded response's link to its source scan.
3. `docs/input_contracts.md` defines what an external OMR decoder must supply (response map, scan file, coordinate map, confidence). State explicitly that bubble detection is out of scope.
4. Importers return structured errors (row, field, reason); no partial silent import.

**Gate 2:** tests for every rejection path and for loading all golden fixtures. Run `pytest -q tests/test_stage2_ingestion.py`; report actuals.
