## S2 — Input Contracts and Import (new)

**Goal:** Define how data enters the system. No scoring.

**Allowed files:** `src/omr_dispatch/models.py`, `config.py`, `ingestion.py`, `docs/input_contracts.md`, `tests/test_stage2_ingestion.py`, `fixtures/ingestion/**`.

**Tasks**
1. Strict Pydantic v2 models (`extra="forbid"`): `SubjectName`, `QuestionMeta` (id, subject, question_type per ADR-0004 with SINGLE_CORRECT supported and others raising NotSupportedError, positive_marks, negative_marks, optional bubble coords), `StudentAdmissionRow` (id, org_id, roll, child_display_name, class_section, Hindi display name/salutation, raw student/guardian contact, sibling-verification, guardian verification, consent status/scope/time/source/reference, revocation), `StudentOMRSubmission` (id, org_id, PRESENT/ABSENT, responses, scan reference, provenance), `MarksEntryRow` (assessment, subject, max_marks, roll_no, status PRESENT/ABSENT, marks as half-mark float/Fraction), `CoordinateMap`, `ScanProvenance`. All models require `org_id: str` and `schema_version: int` (ADR-0006, ADR-0017). A typed `Settings` object in `config.py` validates environment configuration at startup with `SecretStr` for credentials, per-org `include_roll_in_text: bool = False`, and safe defaults (ADR-0009).
2. Importers for roster/answer-key/responses (CSV and JSON) and marks entry totals (CSV/Excel). For marks import: validate 0 <= marks <= max_marks; half marks allowed; blank marks rejected when PRESENT; marks forbidden when ABSENT; blanks never read as zero; duplicate rows rejected; unknown roll numbers reported per row; subject max_marks consistent within an assessment. Reject unknown columns, duplicate IDs, out-of-range question IDs, invalid options, and missing records. Never treat a missing record as zero. Preserve each decoded response's link to its source scan.
3. `docs/input_contracts.md` defines what external OMR decoders and marks entry sheets must supply (response map, scan file, coordinate map, confidence, marks columns). State explicitly that bubble detection is out of scope.
4. Importers return structured errors (row, field, reason); no partial silent import.

**Gate 2:** tests for every rejection path and for loading all golden fixtures. Run `pytest -q tests/test_stage2_ingestion.py`; report actuals.
