## S4 — Conversational Hindi Templates

**Allowed files:** `src/omr_dispatch/hindi_templates.py`, `template_constraints.py`, `tests/test_stage4_hindi_templates.py`. No rendering, audio, or API calls.

**Tasks:** `render_bolchal_templates(report, constraints) -> RenderedBolchalContent` rendering messages defined in `docs/message_catalog.md` (OMR present/absent, marks entry present/absent, PTM slip). Every parent-facing text message names the child (`child_display_name`) and class/section (`class_section`) immediately after a fixed leading greeting (`"प्रिय अभिभावक, "`), never as the first token of the template body (ADR-0010, Decision 5). The roll number is excluded from text by default (`include_roll_in_text=False`). Honor `TemplateConstraints` recorded in S0 (fixed text anchors at both ends, max lengths, no newlines in variables, variable count and fixed-to-variable balance). Text processing follows ADR-0010: Unicode NFC normalization, Latin digit policy (`0-9`) across all numbers, and grapheme-safe truncation (max name length 40 graphemes, fallback `"विद्यार्थी"`). If constraints are `UNVERIFIED`, use the conservative defaults from the spec and mark the output `constraints_unverified=true`.

Rules (D-06, D-07, D-12):
- PRESENT: net/max and one-decimal percentage; "rank X out of N present students" (omit the sentence if rank missing); class average and topper score; with wrong answers show correct count/gross, wrong count, marks deducted, net; without wrong answers say so without implying everything was attempted. Easy-missed copy says **at least** 75% of present students got them right, gives the count and positive marks not earned; if none were missed say "no questions meeting the threshold were missed". Negative nets display with a minus sign.
- ABSENT: neutral grey banner "टेस्ट में अनुपस्थित"; state only that the student is recorded absent, the test maximum, and how many attended. No score, subject diagnosis, absence reason, proof, or signature.
- Subject lines use observable facts ("इस विषय में कोई सवाल हल नहीं किया गया" for `NO_ATTEMPT`); no internal label names are shown.

**Golden assertions:** STU_01 score line conveys "कुल नंबर: 300 में से 55 नंबर आए हैं (18.3%)" enclosed by leading greeting, child name, and class; voice copy says 25 wrong answers deducted 25 marks and the final score is 55; easy sentence: ten missed questions, 40 marks not earned, at least 75% peer accuracy. STU_17 copy: 300-mark test held, 16 students attended, no framing as a zero score. Approved MARKS_ENTRY present message matches Decision 4 literal character-for-character. Sibling distinctness test: STU_05 and STU_06 produce captions differing by child name.

**Gate 4:** test all 20 golden outputs plus all bands, absent, negative net, no-wrong-answers, exactly-75% item, no easy questions, missing rank, odd names/salutations, Unicode normalisation (NFC), long text, template-variable constraints, banned vocabulary, marks entry templates, and sibling-distinctness test. `pytest -q tests/test_stage4_hindi_templates.py`. 🧑 A Hindi-fluent reviewer signs off the golden copy (workflow W7).
